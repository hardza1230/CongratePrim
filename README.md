# งบซอง — Envelope Budgeting

แอปมือถือ (PWA) สำหรับทำงบประมาณแบบซอง แปลงมาจากไฟล์ Google Sheet วางแผนการเงินครัวเรือน
ทำงานได้ทั้งออนไลน์และออฟไลน์ ไม่ต้องติดตั้งอะไร ไม่ต้อง build

## ความสามารถ

| หน้า | ทำอะไรได้ |
|---|---|
| 📊 **ภาพรวม** | สินทรัพย์สุทธิ / สินทรัพย์รวม / หนี้สินรวม, วงแหวนความคืบหน้างบเดือนนี้, สรุปแยกหมวดหมู่, เตือนซองที่ใกล้เต็มหรือเกินงบ, สินทรัพย์ตามเจ้าของ |
| ✉️ **ซอง** | ซองงบประมาณแยกตามหมวด พร้อมแถบความคืบหน้า — แตะเพื่อ **บันทึกจ่าย** (หักจากบัญชีที่เลือกจริง), **โยกเงินระหว่างซอง**, **แก้ไข/ลบซอง**, ดูและลบประวัติรายการ |
| 🗓️ **บิล** | ตารางบิลรายเดือน 12 เดือน × รายการจ่ายประจำ ติ๊กว่าจ่ายแล้ว พร้อมยอดรวมต่อเดือน |
| 🏦 **บัญชี** | บัญชีเงินแยกตามเจ้าของ แก้ยอด/เพิ่ม/ลบได้, รายการหนี้สิน, ปุ่มรีเซ็ตกลับค่าเริ่มต้น |

รายละเอียดอื่น ๆ

- **สลับเดือนได้** ที่แถบด้านบน — ยอดจ่ายจริงและการโยกเงินแยกกันตามเดือน ส่วนงบซองยกมาเป็นค่าตั้งต้นทุกเดือน
- **บันทึกจ่ายครบงบของบิลรายเดือน** ระบบจะติ๊กตารางบิลของเดือนนั้นให้อัตโนมัติ
- **โยกเงินระหว่างซอง** ไม่ทำให้งบรวมเปลี่ยน — ย้ายจากซองหนึ่งไปอีกซองเท่านั้น
- **โหมดสว่าง/มืด** ตามระบบ หรือกดปุ่ม 🌗 มุมขวาบนเพื่อสลับเอง
- ตัวเลขเงินเป็นบาท ปีแสดงเป็น พ.ศ.

## วิธีใช้บนมือถือ

ต้องเปิดผ่าน http/https (ไม่ใช่ `file://`) เพื่อให้ service worker ทำงาน

1. รันเซิร์ฟเวอร์ในโฟลเดอร์นี้ เช่น `python3 -m http.server 8000` แล้วเปิด `http://<ไอพีเครื่อง>:8000` จากมือถือ
   (หรือจะอัปโหลดโฟลเดอร์นี้ขึ้นโฮสต์ไฟล์นิ่งอย่าง GitHub Pages / Netlify / Vercel ก็ได้)
2. **iPhone (Safari)**: ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
   **Android (Chrome)**: เมนู ⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอโฮม
3. เปิดจากไอคอนบนหน้าจอโฮม จะได้แบบเต็มจอไม่มีแถบเบราว์เซอร์ และใช้งานได้แม้ไม่มีเน็ต

## โครงสร้างไฟล์

```
index.html            แอปทั้งหมด (HTML + CSS + JS + ข้อมูลเริ่มต้น) ในไฟล์เดียว
manifest.webmanifest  ข้อมูลแอปสำหรับติดตั้งบนหน้าจอโฮม
sw.js                 service worker แคชแบบ cache-first ให้เปิดออฟไลน์ได้
icon.svg              ไอคอนแอป
```

## ข้อควรทราบเรื่องข้อมูล

ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์บนเครื่องนั้น ๆ

- ไม่ถูกส่งออกไปไหน ไม่มีเซิร์ฟเวอร์หลังบ้าน
- **ไม่ซิงก์ข้ามเครื่อง** — จ๋ากับฮาร์ทเปิดคนละเครื่องจะเห็นข้อมูลแยกกัน
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย และต้องเริ่มจากค่าเริ่มต้นใหม่

ปุ่ม **รีเซ็ตกลับค่าเริ่มต้นจากชีต** อยู่ที่หน้า 🏦 บัญชี ล่างสุด
